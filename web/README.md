# LogCal Web

This folder contains the LogCal website and future web app surface.

## Current Scope

- marketing homepage for `logcalai.com`
- support and privacy routes
- future `/app` route placeholder for the web product

## Commands

```bash
cd web
npm install
npm run dev
npm run build
```

The site is configured as a static export so Firebase Hosting can serve the
generated `out/` directory.
