# LogCal AI Blog Image Prompts

Use these prompts in ChatGPT image generation for the new LogCal AI blog covers. Keep the images region-agnostic, useful, clean, and realistic. Avoid medical claims, tiny unreadable UI text, diet-culture imagery, and body-transformation imagery.

Rule for future prompts: the first line of every image prompt must include the exact article title so the generated image stays anchored to the post topic.

Default blog cover image rules:
- Blog covers should feel like normal editorial visuals, not product ads.
- Do not include LogCal AI branding, LogCal AI logo, branded mobile screens, or phone mockups unless the prompt is specifically for an app/product screenshot.
- The image should explain the article's main idea at thumbnail size.
- Use text only when it helps the image. If text is used, keep it large, short, and readable on mobile/blog-card previews.
- Do not make one supporting fact the whole image. The visual should represent the article's main message.

## 1. How to Estimate Portion Sizes Without a Food Scale

Placement: blog cover image  
Size: 1200x760 landscape  
Alt text: `Visual portion size guide showing plate, bowl, cup, spoon, and handful examples`

Prompt:

```text
Create a premium editorial blog cover image for the article "How to Estimate Portion Sizes Without a Food Scale" for LogCal AI, an AI calorie tracker. Theme: portion size estimation. The image should immediately communicate "this article is about portion sizes" before someone reads the headline.

Scene: a bright, clean top-down layout focused on portion-size references. Show clear, labeled portion examples arranged like a simple visual guide. Include as many of these as can fit without overcrowding:
- quarter plate
- full plate
- cup
- bowl
- spoon
- hand or handful

Use small amounts of simple, generic food inside the references so they do not look empty or abstract. The user should instantly understand this is about estimating portion sizes, not meal inspiration. The image should feel like a friendly portion size guide, not a generic food photo.

Style: realistic lifestyle photography with subtle clean graphic accents, warm natural light, soft shadows, off-white background, green accents matching a friendly health app. Modern, calm, useful, and instructional without looking clinical.

Composition: landscape 1200x760. Use a neat grid or semi-grid arrangement so the portion references are obvious. Prioritize clarity over including every item. If six references feel crowded, include the best five. Keep enough breathing room between objects. No people, except the optional hand/handful reference.

Text: include minimal, clean labels if they help clarity, such as "Quarter plate", "Full plate", "Cup", "Bowl", "Spoon", "Hand". Labels should be large enough to read and spelled correctly. If labels look messy, use fewer labels rather than tiny text.

Avoid: making a full meal the main focus, weighing scales, diet culture imagery, before/after bodies, measuring tape around bodies, exaggerated weight-loss visuals, Indian-specific foods, clutter, stock-photo cheesiness, fake nutrition numbers, tiny unreadable labels.
```
