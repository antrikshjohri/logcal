# Legacy Docs

This folder contains historical docs from earlier development phases.

These files may still be useful for:

- historical context
- old setup approaches
- feature planning history
- troubleshooting notes from earlier iterations

They are not guaranteed to reflect the current codebase.

## Source Of Truth

When a legacy doc conflicts with the current implementation, use:

- [../README.md](../README.md)
- [../SETUP.md](../SETUP.md)
- [../ARCHITECTURE.md](../ARCHITECTURE.md)
- files in `../FEATURES/`

## Typical Examples Here

- earlier Firebase setup notes
- superseded auth docs
- old quick-start guides
- roadmap notes that are no longer tightly aligned to the code
