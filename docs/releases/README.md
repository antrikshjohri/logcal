# Release Notes

This folder contains App Store-facing "What's New" notes for individual releases.

## Purpose

Use these files for:

- App Store submission notes
- release announcement drafts
- version-specific user-facing summaries

## Naming

Create one file per release:

- `WHATS_NEW_V1.6.md`
- `WHATS_NEW_V1.7.md`

## Source Of Truth

Release notes should usually be derived from:

- [../CHANGELOG.md](../CHANGELOG.md)

The changelog is the internal engineering history.
This folder is for polished, user-facing release summaries.
