# What's New in LogCal v1.6

## What's New

### Faster voice logging
Dictation now feels much more natural. You can **start speaking, then send right away** without the extra stop-and-log flow.

### Better recording controls
Voice mode now has clearer controls to **cancel**, **stop and review**, or **send immediately**, so logging by voice feels more intentional.

### Live voice waveform
While recording, LogCal now shows a **live waveform** so it is easier to tell that the app is actively listening.

### Smarter handling of unclear speech
If the app cannot detect clear speech, it now tells you to **try again** instead of turning silence or background noise into a bad log.

### More reliable error feedback
Dictation and network issues now surface more clearly inside the app, so failed logging attempts are easier to understand.
